# Analyzing-Industry-Carbon-Emissions-Datalab
Datalab workbook project - PostgreSQL
data source: The Carbon Catalogue https://www.nature.com/articles/s41597-022-01178-9 (publicly available)
data contains product carbon footprints (PCFs) for various companies and stored in a PostgreSQL database containing one table.
table called "product_emissions"
table looks at PCFs by product as well as the stage of production that these emissions occurred.
Project uses the data to examine the carbon footprint of each industry in the dataset.
